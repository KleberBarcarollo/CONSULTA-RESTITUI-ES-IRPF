# CONSULTA-RESTITUI-ES-IRPF
CONSULTA RESTITUIÇÕES IRPF
Robô para consulta de Restituição de Imposto de Renda via site da Receita.
Sobre este fluxo de automação:
Workflow para realizar a consulta de restituição do imposto de Renda no site da Receita Federal

site: https://servicos.receita.fazenda.gov.br/Servicos/consrest/Atual.app/paginas/index.asp

Esse Workflow faz uso de captcha, portanto é importante criar sua conta no site da DeathByCaptcha.
